# 🚀 AI-Powered Analytics Platform

A cutting-edge analytics platform that transforms your data into actionable insights using advanced AI and machine learning techniques.

## ✨ Features

### 🤖 AI Auto-Insights
**Automatically discover hidden patterns in your data**
- **Anomaly Detection**: Uses Isolation Forest ML algorithm to identify outliers
- **Correlation Discovery**: Automatically finds and ranks the strongest relationships
- **Distribution Analysis**: Detects skewness, kurtosis, and distribution patterns
- **Smart Categorization**: Analyzes categorical data for insights
- **Executive Summary**: One-click overview of your dataset

### 💬 Natural Language Query
**Ask questions in plain English**
- Query your data conversationally: "What is the average sales?"
- Supported queries:
  - Averages and means
  - Sums and totals
  - Maximum and minimum values
  - Unique value counts
  - Correlations between variables
- No SQL or coding required!

### 📊 Smart Visualizations
**AI-recommended charts based on your data**
- Context-aware chart suggestions
- Automatically selects optimal visualization types
- Supports:
  - Histograms for distributions
  - Scatter plots with trendlines
  - Box plots for comparisons
  - Heatmaps for categorical relationships
  - And more!

### 🔮 Predictive Analytics
**Machine Learning-powered forecasting**
- Random Forest regression models
- Feature importance analysis
- Model performance metrics (R², RMSE, MAE)
- Visual predictions vs actual comparison
- Train custom models on your data

### 💎 Data Quality Dashboard
**Comprehensive data health monitoring**
- **Quality Score**: 0-100 overall data health rating
- **Missing Data Analysis**: Identify and visualize gaps
- **Smart Cleaning Suggestions**: AI recommends fixes
- **Duplicate Detection**: Find redundant rows
- **Outlier Detection**: IQR method with visualizations

### 🧪 A/B Testing Lab
**Statistical significance testing made easy**
- Two-sample t-tests
- P-value calculation
- Effect size (Cohen's d)
- Sample size tracking
- Statistical significance indicators
- Visual group comparisons

### 📈 Advanced Statistics
**Professional statistical analysis suite**
- **Normality Testing**: Shapiro-Wilk test with Q-Q plots
- **Confidence Intervals**: 95% CI calculations
- **Hypothesis Testing**: Rigorous statistical tests
- **ANOVA**: Multi-group comparison

### 👥 Cohort Analysis
**Behavioral insights across segments**
- Time-based cohort analysis
- Group-based comparisons
- Metric aggregations
- Trend visualization

### 🎲 What-If Scenarios
**Explore hypothetical outcomes**
- Scenario modeling
- Impact prediction based on correlations
- Interactive sliders
- Visual before/after comparisons

### 📋 Classic Analytics
**All your favorite standard charts**
- Profiling reports
- Box plots
- Histograms
- Scatter plots
- Bar plots
- Scatter matrices
- Crosstabs
- Correlation analysis

## 🚀 Getting Started

### Installation

```bash
pip install -r requirements.txt
```

### Run the App

```bash
streamlit run streamlit_app.py
```

### Usage

1. **Upload your CSV file** - The app accepts any CSV dataset
2. **Choose your analytics mode** - Select from 10 powerful analysis tools
3. **Explore insights** - Let AI guide you to meaningful discoveries
